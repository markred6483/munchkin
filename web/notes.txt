I have a p2p web application.
No centralized beckend nor database is available, just the web server, serving the web page with https protocol, is centralized, but it's static.
The p2p network is full mesh.
Peers exchange messages to change other peers' application state.
There are some actions that I don't want everybody to execute though.
Only high-privilege peers should be able to perform those actions.
So, upon receiving a high-privilege action message, a peer should process it only if the sender has high-privileges.
For a peer, for example PeerA, to aquire high-privileges towards another peer, for example PeerB, PeerA must follow a secure process.
My idea is to store a public key on the web page that everybody can read.
The challenge is as follows:
1) PeerA sends a high-privilege aquisition initiation request to PeerB
2) PeerB checks whether a high-privilege aquisition request from PeerA is already pending (not expired); if so it reuses the old record (go to step 4)
3) PeerB creates a random nonce and saves a record in-memory containing:
3a) the nonce
3b) the timestamp (local clock) of the creation of the nonce
3c) the time-to-live of the nonce
3d) the ID of the initiator, being PeerA
4) PeerB sends the nonce to PeerA
5) PeerA then responds with a message containing:
5a) the nonce
5b) the signed concatenation of the nonce + PeerA's ID, signed with the private key corresponding to the public key on the web page
6) PeerB, upon receiving the message above, will burn the in-memory nonce record
7) PeerB verifies:
7a) whether the peer ID in the last message corresponds to PeerA's ID
7b) whether the nonce is still valid (not expired), calculating the difference between the saved timestamp (local clock) and the current timestamp (local clock)
7c) wheter the requester of the nonce corresponds to the high-privilege action initial requester
7d) whether the signature matches the public key
8) If the checks of the previous step pass, the PeerB will consider PeerA a high-privilege peer from now on
What do you think about this idea?
